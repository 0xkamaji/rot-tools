# RotBot Vision

RotBot may grow into a personal assistant built around an interactive `rot chat` environment—similar to OpenCode—where the user can talk naturally, inspect what RotBot is doing, and approve actions.

Over time, RotBot could become a larger product that builds context for any user and gradually becomes their own personalized assistant.

Possible future capabilities include:

- Running directly on the user’s home server
    
- Integrating with projects, files, services, and server operations
    
- Sending emails or push notifications for cybersecurity updates, reports, completed tasks, and approval requests
    
- Providing a dedicated mobile or desktop app
    
- Supporting secure remote access to a self-hosted RotBot
    
- Keeping personal and project context stored locally
    
- Giving users control over which context is shared with external AI services
    
- Encrypting sensitive stored context
    
- Supporting local AI models for more private workflows
    

The long-term goal is a useful, context-aware assistant that belongs to the user, runs within infrastructure they control, and can be accessed wherever they need it.
